# Left Sidebar Navigation Extension for Pterodactyl 2.0

Transforms the horizontal server navigation into an elegant, vertical left sidebar with active highlights, frosted glass styling, and smooth transitions.

## Features
- Vertical server navigation sidebar on desktop screens (>= 1024px)
- Responsive fallback to horizontal scrollable tabs on smaller viewports
- Modern glassmorphism card styling with active indicators
- Built natively for Pterodactyl 2.0 extension architecture

## Installation
```bash
php artisan p:extension:install extensions/left-sidebar --enable
```
